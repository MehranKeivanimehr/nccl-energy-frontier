# Public export scope

Original scientific archives, original freeze bytes and original allocation
correspondence remain private and unchanged. No omitted file is claimed to
be downloadable from this repository. The file-level
[`FILE_DISPOSITIONS.csv`](FILE_DISPOSITIONS.csv) records each final runtime
file's digest and treatment; [`DERIVATIVES_STAGE2.csv`](DERIVATIVES_STAGE2.csv)
maps original digests to published paths and digests.

All 3 smoke, 23 calibration and 72 held-out launch records and their retained
scientific region/profiler/telemetry/baseline records are published. Private
paths, hardware UUIDs, hostnames and network addresses are replaced by stable
aliases/placeholders. Numeric readings, timestamps, counts, missingness,
acceptance and inferential decisions are unchanged. Counter and telemetry
values are not modified to anonymize identifiers.

Omitted classes are duplicate delivery ZIPs, private authorization/selection
correspondence, superseded gate proposals and packaging utilities, compiler
outputs and external runtime libraries. Necessary scientific rule amendments,
test logs, executed schedules, final source, results and build identities are
retained. Frozen numerical source is byte-identical; it is not cosmetically
rewritten after collection.

The smoke pair/window were selected under recorded user delegation after
availability checks, not individually named by the user. Later permission
and scope checks used the calibration pair. No administrator reservation or
exclusive host access is inferred. A privacy summary is not a rewritten
verbatim authorization. See [`ALLOCATION_SUMMARY.json`](ALLOCATION_SUMMARY.json).

The published Freeze-C/H files are privacy derivative views. Their embedded
hashes describe original files, not the public replacements. Original
Freeze-S is represented by its digest and a selection summary, not its
private text. See [`ORIGINAL_FREEZE_DIGESTS.json`](ORIGINAL_FREEZE_DIGESTS.json).
The new export manifest verifies public bytes; it does not provide an
independent timestamp or prove physical sensor accuracy.

Compiled benchmark, profiler-plugin and external NCCL-library identities
cannot be freshly checked against unavailable original binaries here. Build
records and source are not a substitute for those missing bytes. No new
hardware validation, GPU experiment, historical commit or authorship claim
is created by this export.
